1. EXECUTIVE SUMMARY & PRODUCT IDENTITY
================================================================================
"Telugu Captions" (internally referred to as "Caplio" across internal state, 
cookies, events, and assets) is a specialized, web-based SaaS platform designed
specifically for short-form video creators in the Telugu digital creator ecosystem.

Problem Solved:
Standard automated transcription tools (like Descript, CapCut, or AutoCap) struggle
with Telugu for two reasons:
1. Speech recognition failure on code-mixed "Telugish" (conversational Telugu 
   interleaved with colloquial English words, slang, and film idioms).
2. Lack of dual-script support: Creators require captions in both Native Telugu script
   (తెలుగు) and Romanized Telugu (English alphabet transliteration, e.g., "Meeru ee reel ni...").

Key Value Proposition:
- Upload short-form vertical video (9:16) or standard formats (1:1, 16:9).
- Automatic high-accuracy Telugu speech transcription with code-mixed support.
- Simultaneous Native Telugu script & Romanized English script generation.
- Real-time in-browser caption editor with split, merge, retime, and spell-correction.
- 10+ custom-designed animated caption styles tuned for high-retention Reels.
- Simulated Instagram Reel Safe Zone preview to guarantee captions are never obscured
  by Instagram UI elements (like, comment, share buttons, audio pill, username).
- Server-side burned-in MP4 video rendering with real-time SSE progress streaming.
- Standalone subtitle downloads (.SRT and .VTT).

3. COMPLETE TECHNOLOGY STACK
================================================================================
A. FRONTEND CORE
- Framework: Next.js (App Router architecture with React Server Components)
- UI Library: React 19 (concurrent rendering, useOptimistic, startTransition)
- Build System & Bundler: Turbopack (Turbopack chunking and optimization)
- CSS & Styling: Tailwind CSS v4 design tokens + Curated Vanilla CSS custom properties
  (custom class namespaces: .lp- for landing page, .ed- for editor, .tc- for console)
- Font Engine:
  * NTR (Google Fonts): Primary native Telugu unicode script display font
  * Anton: Condensed high-impact sans-serif for viral "Bold" & "Negative" styles
  * Inter: Standard modern geometric sans-serif for aesthetic styles & app UI
  * Montserrat: Bold modern tracking for "Karaoke" sync
  * Instrument Serif: Editorial luxury serif for aesthetic "Pinterest" styles
  * Geist / Geist Mono: Clean monospaced tags and dashboard analytics

B. BACKEND & CLOUD PLATFORM
- Hosting & CDN: Vercel Edge Network
- Execution Environment: Vercel Serverless Functions (Node.js runtime)
- Storage & Media Upload:
  * @vercel/blob: Client-side multipart token generation & direct S3-compatible blob upload
  * Streaming chunk uploads with progress tracking
  * Direct serverless upload fallback with 'x-filename' headers for files <= 4.2 MB
- Streaming Protocol: Server-Sent Events (SSE) via `text/event-stream` for live render ticks

C. SPEECH RECOGNITION & NATURAL LANGUAGE PROCESSING
- Primary ASR Engine: Sarvam AI (Saaras Indic Speech API) - Specialized for Indian languages,
  fine-tuned for code-mixed Telugu-English conversation, colloquial phrasing, and native accents.
- Secondary / Fallback ASR Engine: OpenAI Whisper (whisper-1 model via REST API)
- Script Transliteration: Sanscript / ITRANS engine for algorithmic phonetic conversion 
  between English Romanized phonetics and Native Telugu script characters.
- Spell Check & Dictionary: Dedicated `/api/spelling` endpoint for Telugu creator vocabulary.

D. VIDEO PROCESSING & COMPOSITION
- Audio Demuxer / Extraction: FFmpeg stream extraction to convert MP4/MOV audio to 16kHz WAV/MP3.
- Subtitle Pipeline:
  * Timed Segment format with word-level start/end timestamps
  * SubStation Alpha (.ASS) generator for burned-in styled animations
  * SubRip (.SRT) generator
  * Web Video Text Tracks (.VTT) generator
- Render Pipeline: Hardware-accelerated FFmpeg H.264 compositor encoding burned MP4 at up to 1080p.

E. AUTHENTICATION & ACCESS CONTROL
- Auth Protocol: NextAuth / Auth.js framework
- Identity Provider: Google OAuth 2.0 (Single Sign-On)
- Server-side route protection: Server Action redirects (`/signin?next=...`)
- Client Theme State: LocalStorage key `caplio-landing-theme` ('light' / 'dark')

4.3 MEDIA UPLOAD & INGESTION ENGINE
--------------------------------------------------------------------------------
The upload workflow handles files of any size with high fault tolerance:
1. Client Validation:
   - Supported extensions: .mp4, .mov, .mkv, .webm, .avi, .m4v, .mpg, .mpeg, .wmv, .flv.
2. Two-Tier Upload Strategy:
   - Primary (Vercel Blob Direct Client Upload):
     * Client calls `POST /api/upload/blob` to request a short-lived presigned upload token.
     * Video file is uploaded directly from the browser to Blob storage using multipart stream.
     * Avoids serverless payload size limitations (bypassing Vercel's 4.5 MB request ceiling).
     * Live upload percentage event updates progress in the UI.
     * On completion, client calls `POST /api/upload/complete` with `{ url, filename }`.
   - Secondary (Direct XHR Fallback):
     * If Blob is unconfigured or the file is smaller than 4.2 MB (4404019 bytes),
       the file is streamed directly to `POST /api/upload` with header `x-filename`.
3. Completion & Routing:
   - Both upload channels return `{ id: videoId }`.
   - The user is automatically navigated to the studio console: `/jobs/${videoId}`.

--------------------------------------------------------------------------------
4.4 AI SPEECH RECOGNITION & TRANSLITERATION PIPELINE
--------------------------------------------------------------------------------
1. Job Processing State Machine:
   - `queued`: Video uploaded and queued for worker execution.
   - `transcribing`: Audio extracted via FFmpeg and dispatched to ASR provider.
   - `processing`: Word alignments, timestamps, and transliteration generation.
   - `completed`: Transcription ready, editor unlocked.
   - `failed`: Failure state with actionable creator error messages and automatic retry.
2. Speech Engine Integration:
   - Driven by environment variable `ASR_PROVIDER`.
   - Sarvam AI: Primary engine specialized in Telugu phonetics and conversational Hinglish/Telugish.
   - OpenAI Whisper: Secondary engine with fallback handling.
   - Long Video Chunking: If video exceeds standard single-pass limits, the system
     automatically splits the audio into sequential chunks and recombines them.
3. Transliteration (ITRANS / Sanscript Engine):
   - Automatically computes Romanized English phonetic representations for every Telugu segment.
   - Gives creators the option to display Native Telugu (తెలుగు), Romanized (Telugish), or both.
4. Real-time Progress Streaming:
   - Client connects to `GET /api/jobs/${id}/stream` via Server-Sent Events (SSE)
     for zero-latency UI updates during processing.
   - Visual HUD during processing displays animated floating Telugu character glyphs (.ed-process-glyphs).

4.7 VIDEO RENDERING & EXPORT PIPELINE
--------------------------------------------------------------------------------
1. Export Initiation:
   - Client sends `POST /api/export/${id}` with:
     * `style`: Complete JSON style parameters.
     * `segments`: Full array of adjusted start/end timestamps and text.
     * `filename`: Validated base filename.
     * `stream`: true (enables live Server-Sent Events).
2. Server-Sent Events Rendering Stream:
   - Response header `Content-Type: text/event-stream`.
   - Yields real-time events:
     `{ status: "processing", progress: 42, renderedSec: 12.6, totalSec: 30.0, filename: "my_reel.mp4" }`
3. Fallback Long Polling:
   - If SSE connection drops, client automatically fails over to `GET /api/export/${id}`
     polling at 800ms intervals up to 450 attempts (~6 minutes max duration).
4. Video Encoding Specifications:
   - Codec: H.264 (AVC) video, AAC audio.
   - Container: MP4.
   - Max Resolution: Up to 1080p (1080x1920 for 9:16 vertical video).
   - Burned subtitle styling executed with pixel-perfect sub-frame accuracy.
5. Export Assets Download:
   - Burned MP4: Available via direct signed blob URL or `/api/export/${id}/file`.
   - Subtitle SRT: Standard UTF-8 SubRip format with sequential numbering.
   - Subtitle VTT: WebVTT format for web players.

5. DETAILED API SPECIFICATIONS
================================================================================

1. POST /api/upload/blob
   - Purpose: Generates client upload token for direct Vercel Blob multipart upload.
   - Headers: Content-Type: application/json
   - Body: `{ pathname: string, clientPayload: string }`
   - Response (200): `{ clientToken: string }`

2. POST /api/upload/complete
   - Purpose: Finalizes uploaded blob and initializes a video job.
   - Headers: Content-Type: application/json
   - Body: `{ url: string, filename: string }`
   - Response (200): `{ id: string, status: "queued" }`

3. POST /api/upload
   - Purpose: Direct multipart upload fallback for files under 4.2 MB.
   - Headers: `x-filename: <encoded_filename>`, Content-Type: video/*
   - Response (200): `{ id: string, status: "queued" }`
   - Error (413): File exceeds serverless upload threshold.

4. GET /api/jobs
   - Purpose: Retrieves list of user's uploaded video projects.
   - Response (200): `Array<{ id, filename, duration, status, createdAt, previewUrl }>`

5. GET /api/jobs/${id}
   - Purpose: Retrieves full metadata, video source URL, and transcript status.
   - Response (200): `{ id, filename, status, videoUrl, duration, segments: [...] }`

6. GET /api/jobs/${id}/stream
   - Purpose: SSE real-time stream of transcription and processing status.
   - Response Header: `Content-Type: text/event-stream`
   - Event Payload: `{ status: "queued"|"transcribing"|"processing"|"completed"|"failed", progress: number }`

7. POST /api/jobs/${id}/retry
   - Purpose: Retries a failed transcription job with audio splitting.
   - Response (200): `{ status: "queued", progress: 0 }`

8. GET /api/transcript/${id}
   - Purpose: Fetches timed subtitle segments for video.
   - Response (200): `{ segments: Array<{ start, end, text, words: [...] }> }`

9. PUT /api/transcript/${id}
   - Purpose: Updates edited subtitle segments and timings.
   - Body: `{ segments: Array<{ start, end, text, words: [...] }> }`
   - Response (200): `{ ok: true }`

10. POST /api/export/${id}
    - Purpose: Initiates video rendering with burned captions.
    - Body: `{ style: object, segments: array, filename: string, stream: boolean }`
    - Response: SSE stream or JSON `{ status, progress, url }`

11. GET /api/export/${id}
    - Purpose: Polling endpoint for video export completion.
    - Response (200): `{ status: "idle"|"processing"|"completed"|"failed", progress: number, url?: string }`

12. GET /api/export/${id}/file
    - Purpose: Direct binary download stream of the exported MP4 video.
    - Response: `Content-Type: video/mp4`, `Content-Disposition: attachment`

13. GET /api/billing/usage
    - Purpose: Retrieves creator's available minutes, plan name, and quotas.
    - Response (200): `{ prepaidMinutes: number, monthlyMinutes: number, usedMinutes: number, planLabel: string }`

14. POST /api/spelling
    - Purpose: Corrects or suggests spelling for Telugu transliterated and native words.
    - Body: `{ query: string, script: "telugu"|"romanized" }`
    - Response (200): `{ suggestions: string[] }`

8. PERFORMANCE, SECURITY & SCALABILITY ANALYSIS
================================================================================
1. Performance Optimizations:
   - Vercel Blob client upload bypasses server bottlenecks, uploading directly to S3 storage.
   - Video preview renders in native HTML5 canvas with hardware acceleration.
   - Text animations use GPU-accelerated CSS transforms (translate3d, scale) rather than layout recalculations.
   - Debounced network saves for transcript edits prevent server flood during rapid typing.
   - Fonts use `font-display: swap` with preloaded WOFF2 subsets to prevent FOIT (Flash of Invisible Text).
2. Security & Data Protection:
   - Route-level middleware ensures unauthenticated requests to `/library`, `/billing`,
     and `/jobs/[id]` automatically redirect to `/signin`.
   - Vercel Blob tokens are short-lived, single-use presigned tokens.
   - Filename sanitization (`normalize("NFC")`, strict regex checking against path traversal).
   - Video privacy: Processing storage files are automatically scrubbed after rendering.
3. Scalability Considerations:
   - Serverless architecture automatically scales with creator traffic spikes.
   - Separation of transcription (Sarvam AI / Whisper API) and video rendering (FFmpeg)
     allows each stage to scale independently.

9. COMPETITIVE ADVANTAGES & BUSINESS LOGIC
================================================================================
Why "Telugu Captions" succeeds over global caption tools:
1. Native Code-Mixed Speech Accuracy:
   Telugu influencers speaking on camera constantly switch between Telugu and English.
   Mainstream models produce gibberish for code-mixed phrases; Sarvam AI-backed transcription
   captures exact creator intent.
2. Dual-Script Romanized & Telugu Support:
   A huge portion of younger Telugu audiences reads Romanized script ("Ela unnaru?") rather
   than formal Telugu script ("ఎలా ఉన్నారు?"). Telugu Captions supports both formats natively.
3. Zero Obscurity with Instagram Safe Zones:
   Creators waste hours re-exporting videos when Instagram's UI covers up subtitles.
   The real-time safe zone simulator guarantees 100% readability on mobile feeds.
4. Micro-pricing tailored for Indian creators:
   Instead of demanding $20+/month in USD, pricing is anchored to Indian UPI reality:
   ₹9 per video or ₹59 per week.
5. Hyper-Local Cultural Affinity:
   "Made in Hyderabad for Telugu creators" establishes trust, local relevance, and strong
   word-of-mouth distribution in the Tollywood and Telugu digital creator ecosystem.
